## About

MaiCoin集團為台灣歷史悠久的數位資產交易集團，成立於2014年，提供虛擬貨幣的交易服務，業務包含 MaiCoin 數位資產買賣平台、MAX 數位資產交易所、AMIS 帳聯網公司、Qubic 區塊鏈技術整合服務。

- MaiCoin 數位資產買賣平台於 2014 年正式上線，支援新台幣、美元出入金，提供比特幣（BTC）等虛擬貨幣代買代賣服務，為台灣首個可以法幣交易以太幣（ETH）、萊特幣（LTC）、USDT 等虛擬貨幣的平台，另提供定期定額買虛擬貨幣、MaiCoin PAY 虛擬貨幣支付等服務；2025 年取得涵蓋全公司的 ISO 27001 國際資安驗證，完成金管會洗錢防制登記。

- MAX 數位資產交易所於 2018 年成立，提供新台幣對虛擬貨幣之交易，服務推出 7 個月交易量即突破新台幣 54 億元，亦獨步全球首創法幣資金信託保管機制，具備台灣市場深度流動性、高效撮合引擎、多層次風險控管機制；2025 年取得涵蓋全公司的 ISO 27001 驗證、完成金管會洗錢防制登記。

- AMIS 帳聯網路科技股份有限公司成立於 2016 年，以太坊聯盟的創始成員之一，獨家專利技術包含伊斯坦堡拜占庭共識演算法、Alice 階層式門檻簽章技術，提供 AMIS Custody 企業級數位資產保管服務與 Qubic NFT 技術整合服務， AMIS 曾通過 SOC 2 Type I 及 Type II 安全性稽核及 ISO 27001 國際資安驗證。

- Qubic 區塊鏈技術整合服務為帳聯網路科技公司旗下服務，於 2021 年上線，主要業務涵蓋企業級區塊鏈技術與 NFT 服務整合，協助企業靈活導入區塊鏈技術，並提供可擴展的解決方案。Qubic 亦專注於普及去中心化應用，透過 Qubic Wallet 簡化 Web3 產品的使用流程，降低一般用戶的進入門檻，讓大眾無需理解艱深的技術，即可體驗區塊鏈應用。
